# co2displacement

Script for Salcido et al. CO2 displacement manuscript. The main analysis is in `co2_displacement_figures.Rmd`
(with knitted `co2_displacement_figures.html` for easy viewing). Three small auxiliary data files
needed for the analysis are also present.

**Primary sensor datasets are archived at HydroShare**  
- Pecan orchard: https://www.hydroshare.org/resource/760ee7dd79ec4d819fc106aed1e79f0a/  
	File: pecan_fine_clean.csv.gz
- Bajada shrubland: https://www.hydroshare.org/resource/5b3e057e9264427c9fafa5d6305498f1/
	<br>File: sat_site_clean.csv.gz

## How to run
1. Download sensor data above from hydroshare and auxiliary data files from above.
2. Ensure all data files and `co2_displacement_figures.Rmd` are in the same folder.
3. Open `co2_displacement_figures.Rmd` in RStudio.
